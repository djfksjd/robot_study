## 진행 팁

- AI 답이 틀리는 순간이 가장 좋은 교육 소재다. "AI가 틀린 점" 칸을 반드시 채우게 한다.
- 시뮬레이션 성공을 실제 로봇 성능으로 말하지 않게 한다. 웹 시뮬레이터는 운동학, MuJoCo는 단순화된 물리다.
- STOP과 안전 게이트는 "AI가 잘하면 필요 없는 기능"이 아니라 "AI가 틀려도 안전하게 만드는 기능"임을 강조한다.
- 학생이 모델(`scara_params.json`)을 바꿨다면 마지막에 `git checkout model/scara_params.json` 으로 되돌리게 한다.
