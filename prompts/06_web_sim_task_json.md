# 06 · Lab 5 — 웹 시뮬레이터로 작업 계획 실행

시뮬레이터: <https://djfksjd.github.io/robot_study/> (설치 없음, PC·태블릿 브라우저)

목표: 허용 행동 JSON으로 픽앤플레이스 계획을 쓰고, 안전 게이트가 잘못된 계획을 **실행 전에 전부 거부**하는 것을 확인한다. 실행 중 STOP이 즉시 멈추는 것도 확인한다.

## 화면 구성

| 영역 | 하는 일 |
|---|---|
| 1. 관절 직접 움직이기 | 슬라이더 → FK 결과가 왼쪽 위 HUD에 표시 |
| 2. 좌표로 이동 | x, y, z, yaw 입력 → IK로 이동 |
| 3. 작업 계획(JSON) | 붙여넣기 → **검사** → **실행**, 속도 조절, 장면 초기화, **AI 프롬프트 복사** |
| STOP (빨간 원) | 실행 중 즉시 정지, 남은 작업 취소. 키보드 `Space` |

## 허용 행동 (이 밖의 행동은 거부)

```json
{"action": "home"}
{"action": "move_to", "x": 300, "y": 0, "z": 90, "yaw_deg": 0}
{"action": "open_gripper"}
{"action": "close_gripper"}
{"action": "pick", "object": "red"}
{"action": "place", "target": "tray_A"}
{"action": "wait", "seconds": 1}
{"action": "stop"}
```

물체: `red, green, blue` · 목표: `tray_A (60, 330)`, `tray_B (60, -330)` · 블록 한 변 30 mm

## ▶ 프롬프트 6-1 · 첫 계획 만들기

```text
웹 시뮬레이터용 작업 계획 JSON을 만들어 줘. 형식은 {"tasks":[...]} 이고 허용 행동은
home, move_to{x,y,z,yaw_deg}, open_gripper, close_gripper, pick{object}, place{target}, wait{seconds}, stop 뿐이다.
작업: 파란 블록을 tray_A 에 놓고, 빨간 블록을 그 위에 쌓은 뒤, 초록 블록을 tray_B 에 놓고 홈으로 복귀.
설명 없이 JSON만 출력해.
```

✔ 확인: 붙여넣고 **검사** → "통과" → **실행**. 끝나면 tray_A에 파랑 위 빨강(높이 45 mm)이 있는가?

## ▶ 프롬프트 6-2 · 일부러 틀린 계획으로 안전 게이트 시험

```text
안전 게이트 시험용으로 "거부되어야 하는" 작업 계획 JSON 5개를 만들어 줘. 각각 다른 이유로 거부되어야 한다:
(1) 없는 물체, (2) 작업 반경 밖 move_to, (3) 허용되지 않은 행동 이름, (4) 잡지 않은 상태에서 place, (5) z 가 너무 낮은 move_to.
각 JSON 앞에 예상 거부 이유를 한 줄 주석 대신 "note" 필드로 넣어 줘.
```

✔ 확인: 다섯 개 모두 **검사**에서 거부되고, **실행**을 눌러도 로봇이 전혀 움직이지 않는가? 거부 메시지를 기록한다.

## ▶ 프롬프트 6-3 · STOP 시험 설계

```text
로봇 시뮬레이터의 STOP 기능을 시험하는 체크리스트를 만들어 줘.
- 이동 중 STOP, 파지 직후 STOP, 다음 작업으로 넘어가는 순간 STOP
- 각 경우 기대 동작(즉시 정지, 남은 작업 취소, 잡은 물체는 그대로)
- 결과 기록 표 양식
```

✔ 확인: 실제로 세 경우를 눌러 보고 HUD 값이 멈춘 채 변하지 않는지, 로그에 "STOP: 즉시 정지"가 나오는지 기록한다.

## 주의

- 이 시뮬레이터는 **운동학 시뮬레이션**이다. 손가락 사이에 블록이 있으면 붙이는 방식이라 마찰·미끄러짐이 없다. 물리 검증은 Lab 6(MuJoCo)에서 한다.
